How to Install

Download the .mcaddon file, open it with Minecraft Bedrock Edition and allow Minecraft to import the included Behavior Pack and Resource Pack.

Jovaryn Games add-ons are independently created projects and are not affiliated with Mojang or Microsoft.

ABOUT THE STUDIO

Building Experiences One Project at a Time.

Jovaryn Games is an independent game development studio focused on creating browser games, Minecraft Bedrock add-ons, interactive adventures and creative digital experiences.

The studio began with web development and browser games and is now expanding into custom Minecraft Bedrock gameplay systems, creatures, items and original experiences.
